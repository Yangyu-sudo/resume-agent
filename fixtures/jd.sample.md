# 高级前端工程师（交易链路）

## 岗位职责

1. 负责核心交易链路的前端架构与开发，保障大促期间稳定性。
2. 主导性能优化与首屏指标治理，持续跟踪 LCP、INP 等核心指标。
3. 参与 Node.js BFF 层建设，与后端协作设计聚合接口。
4. 参与微前端改造，推动微前端框架在多团队间落地。

## 任职要求

1. 本科及以上学历，5 年以上前端开发经验。
2. 精通 React 与 TypeScript，熟悉 Hooks、状态管理与组件设计。
3. 熟悉前端工程化：构建工具（Vite / Webpack）、CI/CD、单元测试。
4. 有 Kubernetes 部署与容器化实践经验者优先。
5. 有性能优化与监控体系建设经验者优先。
6. 有团队管理与跨团队协作经验者优先。

## 加分项

- 了解微前端框架原理，有实际迁移经验。
- 有中大型电商系统经验。
